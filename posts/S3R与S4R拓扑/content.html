S3R 与 S4R 拓扑 — 费曼学习法笔记

学习日期：2026-10-19 | 方法：费曼学习法 | 领域：航天器（卫星）电源调节 PCU

一、核心问题

理解卫星电源系统里 S3R / S4R 两种拓扑：它们各自解决什么问题、靠什么机制工作、两者唯一的硬件差别带来了哪些连锁影响。

二、关键概念

1. 名字本身就是答案（数 S 的个数）

缩写 全称 S 的个数 中文
S3R Sequential Switching Shunt Regulator 3 个 S（S³R） 顺序 开关 分流 调节器
S4R Sequential Switching Shunt Series Regulator 4 个 S（S⁴R） 顺序 开关 分流 串联 调节器

S4R = S3R + 一个串联开关。多出来的第 4 个 S（Series，串联）就是两者唯一的硬件差别，也是全部优劣的来源。

2. 基本术语

术语 含义
太阳阵段（SA section） 把整块太阳电池板切成的 N 个独立发电单元，本质是电流源（电流由光照决定，不可调）
分流开关（shunt switch） 并联在段两端的开关（低 Rds(on) MOSFET）。闭合 = 该段被短路，电不被取出
串联开关（series switch） S4R 新增，串联在段与蓄电池之间。闭合 = 该段电流直灌电池充电
MEA Main Error Amplifier，主误差放大器。检测母线电压，产出误差信号
顺序逻辑 由 MEA 信号驱动的一串比较器，决定"派哪一段值班"
值班段（active section） 同一时刻唯一在做高频开关调节的那一段
BCR Battery Charge Regulator，蓄电池充电调节器（传统方案里的独立 Buck）

三、S3R 是怎么工作的

两句话：

  1. 分而治之 —— 太阳阵切成 N 段，每段自带分流开关。开关闭合 → 该段短路、电被丢弃；开关断开 → 该段的电顶上母线。
  2. 顺序值班 —— 同一时刻只有一段在高频开关微调母线电压；其余段要么全导通（全力供电），要么全短路（直接丢弃）。值班段饱和时，调节权顺序移交给下一段。

为什么这样做好

优点 原因
开关损耗极低 同一时刻只有一段在高频开关
EMC 极好 没有 N 路 PWM 同时动作的噪声叠加
滤波器可以做得很小 母线纹波小 → 省体积重量（卫星上极贵）
可靠性高、天然冗余 段是模块化的，滞环 + 顺序逻辑，无需复杂 PWM 芯片
太阳阵辐射干扰小 绝大多数段处于稳态，太阳阵这块"巨型天线"上几乎没有高频纹波电流

代价

  • 太阳阵不工作在最大功率点（非 MPPT）：每段要么全供要么全扔，母线电压被钳死 → 太阳阵串联片数必须按母线电压设计。
  • 分流的段会发热（见追问 2）。
  • 段数越多调节越精细，但硬件越多。

四、S4R 解决了什么问题

S3R 只管稳母线，不管充电。给电池充电要另配一台 BCR（通常是母线取电的 Buck）：

太阳能 → 母线 → BCR(Buck) → 蓄电池   ← 两级变换

两级变换 = 两次损耗 + 一整台大功率 Buck 的重量体积。

S4R 的点子：既然每段本来就有分流开关，再给它加一个串联开关直连电池。于是每段有了三种状态：

状态 分流开关 串联开关 这段的电去哪
① 丢弃 闭合 断开 短路，功率不被取出（冗余功率）
② 供电 断开 断开 经二极管顶上母线
③ 充电 断开 闭合 直灌蓄电池（单级直达）

关键：S4R 依然保持"顺序"特性 —— 同一时刻依旧只有一段在高频开关（无论调母线还是调充电电流）。所以 S3R 的全部优点原样继承，同时把充电从两级压成单级，砍掉一整台 BCR。

五、追问回顾（盲区在这里）

追问 1：值班段凭什么能"精细"调节？它不是只会开和关吗？

我的回答：依赖主误差信号，主误差信号由母线电压比例变换而来。
评价：✅ 对了控制信号的来源，❌ 但漏了执行机构。

正确答案：误差信号本身不产生"中间值"。真正的机制是 —— 值班段的分流开关做高频 PWM（或滞环）开关，靠占空比的时间平均调出中间值。比如 30% 时间短路 + 70% 时间供电，平均下来这段就贡献 70% 的电流。"精细"来自时间维度的平均，不是模拟量连续调节。另外 MEA 信号还兼管"派哪一段值班"。

追问 2：分流开关短路后，能量是不是耗散在 MOS 管上、流向大地了？

我的回答：使用 MOS 管导通电阻小，多余的能量给了大地。
评价：⚠️ 这条是错的，而且是经典误解。

正确答案：

  1. 卫星上没有"大地"。分流是就地短路，电流只在「太阳阵段 → 开关 → 太阳阵段」这个小回路里循环，不流向任何地。
  2. 能量主要不是耗散在 MOS 管上。关键是：段被短路时 V ≈ 0，所以 P = V·I ≈ 0 —— 这段电根本没被取出来。没被取出的太阳能变成热量留在太阳电池板自己身上（电池片工作在短路点，光能→载流子→复合发热）。MOS 管只承受 I²·Rds(on) 这一小点导通损耗（所以才要选低 Rds(on)）。

工程后果：分流时太阳阵会升温，所以分流调节的太阳阵必须专门做热设计。

追问 3：母线调节和充电调节打架吗？谁优先？

我的回答：母线优先级高。
评价：✅ 正确。

补充：MEA 是主环，母线要多少先给多少，剩下的富余功率才分配给电池充电。S4R 里这个"分配"就是靠决定有多少段进入"串联充电"状态来实现；同时充电还受电池限流/限压保护约束（不能过充）。

追问 4：不搞"顺序"，让 N 段全部一起 PWM 会怎样？

我的回答：EMI 大。
评价：⚠️ 只答对 1/4，而且 EMI 不是最致命的。

完整答案：

  1. 开关损耗 × N（最致命） —— 每段都高频开关，损耗成倍上升，效率显著下降。对靠太阳能过日子的卫星是硬伤。
  2. 需要大滤波器 —— N 路纹波叠加，母线滤波电容/电感要大幅加大 → 又重又占体积（发射成本极高）。
  3. EMI / 辐射 ✅ —— 而且有个卫星特有的点：太阳阵本身就是巨大的"天线"，在上面跑高频纹波电流会直接辐射干扰。
  4. 可靠性下降 —— N 路 PWM 要同步/交错，故障模式变多，失去"单段开关"带来的低应力长寿命优势。

六、知识框架（Step 4 提炼）

一句话版（讲给外行听）

卫星的太阳板发的电用不完又存不下，S3R 的办法是把太阳板切成 N 段，用不着的段直接短路扔掉，并且同一时刻只让一段在快速开关来精确稳住电压；S4R 则给每段再加一条直通电池的开关，让充电不再绕道母线、省掉一整套充电设备。

类比总结

N 个水龙头往浴缸放水，每个龙头出水量固定（拧不小）。

  • S3R：需要多少水就全开几个龙头，但只允许一个龙头处于"快速开开合合"的微调状态来精确稳住水位；其余要么全开，要么关掉让水流进地漏（= 短路分流）。因为只有一个龙头在滴答，所以噪音小、磨损小。
  • S4R：在浴缸旁再放一个蓄水池（电池），并且给每个龙头加一根可以直接通到蓄水池的管子。原来要先放进浴缸、再用水泵（BCR）抽进蓄水池（两级）；现在龙头一拧就直接流进蓄水池（单级），水泵全省了。

九、深入专题：太阳阵分段数 N 与母线纹波（定量）

核心结论：母线纹波 ∝ 1/N —— N 翻倍，纹波减半。

原因：S3R 的定义决定了同一时刻只有一段在高频开关，与 N 无关；N 增大只是让每一段的电流更小（I_sec = I_SA / N），于是注入母线的电流台阶更小。

推导

值班段向母线注入 0 ↔ I_sec 的方波电流（分流开关闭合 → 不供电；断开 → 供 I_sec），该方波被母线电容积分成三角波电压：

  • 容性分量：ΔV_C = I_sec · d(1−d) · T_s / C_bus，d = 0.5 时最大 → ΔV_C,max = I_SA · T_s /(4 · N · C_bus)
  • ESR 台阶：ΔV_ESR = I_sec · R_esr = I_SA · R_esr / N

两项都正比于 I_sec，即反比于 N；且都与 C_bus、T_s 成反比。

数值算例

取 V_bus = 100 V、I_SA = 100 A、C_bus = 470 µF、f_s = 20 kHz、ESR = 10 mΩ：

NI_sec容性纹波ESR 台阶合计（相对 100 V）
250 A1.33 V0.50 V1.83 %（超 1% 规范）
425 A0.66 V0.25 V0.92 %
812.5 A0.33 V0.13 V0.46 %
166.25 A0.17 V0.06 V0.23 %
323.13 A0.08 V0.03 V0.11 %

曲线是双曲的：前几段收益极陡，之后边际收益迅速变平。

二阶红利：N 大了还顺带省损耗

损耗项与 N 的关系
开/关重叠损耗 V_bus · I_sec · t_cross · f_s∝ 1/N
段寄生电容损耗 C_sec · V_bus² · f_s（C_sec = C_SA/N）∝ 1/N
分流管导通损耗 I_sec² · R_ds(on)∝ 1/N²

总开关损耗 ∝ 1/N。若把“总开关损耗预算”固定，N 增大释放出的预算可用于提高 f_s，此时容性纹波理论上可压到 ∝ 1/N²；但 ESR 台阶与 f_s 无关，只随 1/N 走 —— 高频段 ESR 成为瓶颈，必须靠多只低 ESR 电容并联。

常见误解

  1. “段多了，开关的段就多了，纹波更大” —— 错。同时开关的段数恒为 1，与 N 无关；N 增大只是让这一段更小、更温和。
  2. “提高 f_s 就能替代加大 N” —— 只对容性分量成立。ESR 台阶压不住；且 f_s 上升会让段寄生电容损耗线性增加，并让太阳阵（一块巨型天线）辐射恶化。
  3. “加大母线电容就行” —— 容性分量 ∝ 1/C 确实有效，但航天上大电容又重又贵（铝电解基本不可用，靠薄膜/陶瓷）；ESR 台阶取决于并联后的总 ESR。

N 的上限：几条硬墙

  • 每段电压必须 ≥ V_bus + V_D → 每段串联片数被母线电压锁死，只能按并联电池串（string）分组 → N ≤ 并联 string 总数（最硬的物理约束）
  • SADA 滑环通道数：每段至少 1~2 根引线过滑环，N 段占 N+1 ~ 2N 个通道，滑环通道是整机稀缺资源
  • 线束重量：2N 根导线从太阳阵拉到平台，长数米，直接计入发射成本
  • 开关 / 隔离二极管 / 驱动 / 保护 ×N：故障点增多（但单段失效只损失 1/N 功率，N 大反而容错更好）
  • MEA 顺序逻辑：N 级比较器链或数字排序，复杂度随 N 上升

选型口诀：纹波 ∝ 1/N，开关损耗 ∝ 1/N，硬件代价 ∝ N；下限由纹波规范（常 ≤1%）定，上限由并联串数与滑环通道封顶。实际飞行型号常见 N = 12~32，且常不等分（按负载台阶与 string 分布配置）。
